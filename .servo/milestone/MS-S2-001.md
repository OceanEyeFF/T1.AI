## Purpose

当前阶段先把“股票池分层定义”变成可复用的工程契约。目标是让后续研究不再依赖口头的“大盘池”“低控盘概率池”“疑似控盘池”等描述，而是通过稳定 `stock_pool_id`、版本、构造方法、基础宇宙、筛选字段、TuShare 数据获取预算、导出产物和元数据进入训练 / 评估链路。

## Scope

### In Scope

- 股票池分层 taxonomy：基础可交易池、大盘 / 中小盘层、低控盘概率候选层、疑似控盘 / 小盘观察层的定义边界。
- TuShare 获取策略与请求上限契约：优先复用现有缓存，新增请求必须先 dry-run 估算 endpoint、股票数、日期范围、请求数、小时预算、1H 频率墙、time-waiting / resume 策略和 blocked-by-quota 处理。
- A2 测试环节：在策略设计之外，必须用无网络或低风险模拟测试验证请求预算、限流等待、断点续跑、缓存命中和 blocked-by-quota 行为。
- 分析策略与数据源字段映射：用 `daily_basic` 的市值 / 流动性 / 换手代理、日线量价稳定性和可选 `moneyflow` 代理构造分层；不得把 proxy 直接宣称为真实控盘概率。
- registry 命名与版本规则：明确哪些池子进入正式 `stock_pool_id`，哪些只能作为 research-only。
- 首批样例池定义：在既有 `csi300`、`custom_*` 与 `sector_*` 家族基础上补齐本轮需要的样例或配置草案。
- 最小导出 / 加载 smoke：验证新样例池能被 registry loader 读取并导出 `symbols_csv` 与 `metadata_json`。
- 下游复验契约：说明后续“大盘低控盘概率池 3/5/10d 复验”应消费哪些池子、记录哪些 metadata、哪些结论不能提前宣称。

### Out Of Scope

- 大盘低控盘概率池 3/5/10d 复验本身。
- `pred_3d` / `pred_5d` / `pred_10d` 或 `alpha_score` 的训练、优化、晋级、默认启用。
- 决策模型、交易逻辑、目标仓位、订单生成、生产调度。
- 未经单独确认的 live 数据源调用、外部付费 / 配额消耗调用、release、tag、push。
- 分钟级 `stk_mins` 获取或 1d 日内模型研究。
- 小盘 / 疑似控盘池的完整“控盘 / 拉升前状态识别”模型。

## Acceptance Criteria

- 每个股票池层必须说明“用途、构造字段、排除规则、版本升级条件、是否 research-only”。
- 低控盘概率相关层必须以 proxy / candidate 命名和解释，不得把 TuShare 派生指标宣称为真实控盘概率。
- TuShare 获取策略必须包含 endpoint 清单、cache coverage 检查、dry-run 请求数估算、`max_requests_per_hour` / `sleep_seconds` / batch 参数、1H 频率墙下的 time-waiting / resume 策略、失败重试边界和 blocked-by-quota 记录。
- A2 必须包含测试证据，至少覆盖请求预算 dry-run、缓存命中避免请求、限流等待调度、进程中断后 resume、不足 quota 时 blocked-by-quota 输出；测试不得真实消耗 TuShare quota，除非 Worktrack contract 或用户单独批准。
- A2 关闭后必须做一轮中途审查，审查内容至少覆盖 A2 测试证据、1H 频率墙等待 / resume 策略、blocked-by-quota 行为、真实 quota 调用边界，以及 A3 是否可使用 quota-consuming fetch path；审查通过前不得初始化 A3。
- 正式实验 metadata 不允许使用“默认池”“大盘池”“低控盘池”等口语化 ID。
- 样例池必须能追溯到 `stock_pool_id`、`stock_pool_version`、`construction_method`、`base_universe`、`symbols_source`、`symbols_count`、`data_end_date`、`source_endpoints` 和 `fetch_manifest`。
- 若控制概率或类似 proxy 字段缺失，必须输出 blocked-by-data 或 contract-only 结论，不得手工伪造可用池。
- smoke 只证明 registry 链路可运行，不证明模型有效。
- 最终报告必须明确后续 3/5/10d 复验的输入契约，并再次声明复验与信号晋级不属于本 Milestone。
