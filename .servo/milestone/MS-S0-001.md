## Purpose

当前项目需要 decision-ready signals，但 `3d/5d/10d` 预测尚不能默认视为可用交易 alpha。本 Milestone 的目标是先建立可信评估范式、排除伪信号、设计预测优化实验队列，并明确 `alpha_score` 何时可以、何时不可以进入默认决策模型评估。

## Scope

### In Scope

- `3d/5d/10d` 主线预测可信评估范式。
- Daily-CS IC / RankIC、月度稳定性、trade-like panel 的主次关系。
- 标签成熟日、交易时点、复权口径、停牌、涨跌停、样本筛选和成本假设检查。
- shuffle、time reverse、lag-1、随机标签、行业 / 市值中性化等防伪检查。
- LSTM、XGBoost 与轻量融合候选的同窗比较和优化实验队列。
- `alpha_score` 晋级、降级、no-go、continue-research 的规则。
- `1d` 日内数据源可用性只读验证，作为独立研究线的前置事实。
- 决策模型 C0 输入 / 输出草案，作为下游约束，不进入交易逻辑实现。

### Out Of Scope

- 将 `1d` 信号并入默认 `alpha_score`。
- 使用 day-K-only `1d` 结果证明或否定超快速预测方向。
- 在主线预测未通过可信门禁前实现复杂决策模型 C1/C2/C3。
- 真实下单、生产调度、外部生产 API 调用、发布、版本标签或推送。
- 恢复多 worktree 并行开发。

## Acceptance Criteria

- 高 IC 或高月胜率结果必须通过防伪检查后，才允许作为可信候选。
- 评估报告必须能区分真实排序能力、时序错位、样本选择、校准技巧和聚合技巧。
- 未通过 A2/A3 前，`alpha_score` 只能作为 candidate research signal，不能作为默认可交易信号。
- A3 必须输出至少一个候选模型的 go / no-go / continue-research 判断；若证据不足，必须显式保持 continue-research。
- `1d` 线必须在 B0 数据可用性通过前保持独立，不进入主线默认 scoring。
- 决策模型在本 Milestone 内最多推进 C0 I/O 草案，不进入复杂换仓、成本覆盖、风控禁买或组合学习实现。
- 所有 Worktrack closeout 后，Milestone Gate 必须覆盖 black-box、white-box、anti-cheat 和 composite acceptance lanes，且最终验收需要 programmer 决定。
