## Purpose

当前 21 个一级目录是探索期多线并行的遗留。`src/ashare_lab/` 已成为训练流水线主体后，外围目录没有同步收束。

目标：建立 `inputs/ → workspace/ → outputs/` 三区模型，让目录语义直接反映流程架构：

- `inputs/` = "用什么训练？"（数据湖 + 选股池 + 配置档案）
- `workspace/` = "训练过程中产生了什么？"（checkpoint + 运行日志 + registry）
- `outputs/` = "模型产出了什么可用的？"（预测 + 报告 → 交易层消费）

## Scope

### In Scope

- 一级目录重组：data/ → inputs/data/、models/ → workspace/checkpoints/、output/ → outputs/、logs/ → workspace/runs/
- configs/ 内容迁移到 inputs/configs/ 并重组子目录（profiles/ experiments/）
- configs/stock_pools/ 移动到 inputs/pools/
- .gitignore 更新（覆盖新位置、排除 __pycache__/）
- docs/ 子目录扁平化
- 所有硬编码路径的修复（scripts/ configs/ src/ deployment/）
- 全量 pytest 回归
- 文档入口更新（README.md 等）
- 激进行清理：删除 data/datasets/_smoke_*、旧 checkpoint、旧 recommendation JSON

### Out Of Scope

- src/ashare_lab/ 内部模块重组
- TuShare 数据湖构建（后续 Milestone）
- 模型重训练或超参调整
- Pipeline 业务逻辑变更
