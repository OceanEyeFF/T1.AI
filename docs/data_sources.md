# 数据来源（V0：akshare）

目标：先把“可复现回测链路”跑通；数据源先用 akshare，后续再接入更稳定的数据服务（例如 tushare pro）。

## 行情（股票日线）

- 来源：akshare `stock_zh_a_hist`
- 用途：开高低收量额（本仓库 V0 使用前复权 `qfq`）
- 风险点：
  - 不同源的复权口径/复权因子更新可能不一致，切换数据源必须重跑全量回测
  - 分红送转会影响价格序列，必须统一复权口径

## 指数基准（沪深300）

- 来源：akshare `index_zh_a_hist(symbol="000300")`
- 用途：作为超额收益对照（见 `docs/objectives.md`）

## 股票列表/股票池元数据（可选）

V0 只支持手动传入 symbols；后续可用 akshare 的 A 股列表接口构建股票池，并按 `docs/constraints.md` 做过滤。

## 公告/新闻（可选插件）

V0 不强依赖新闻。若引入文本事件，建议优先：
- 公告/正式披露文本（信息密度高、时间戳更可控）
- 其它新闻/舆情只作为可插拔数据源，并存档原文（支持复跑与审计）
