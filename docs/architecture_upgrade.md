# 架构升级设计文档

**版本：** v1.0
**创建日期：** 2025-01-26
**目标：** 基于 LSTM + 高级因子 + LLM 增强的智能量化预测系统

---

## 1. 升级背景与目标

### 1.1 当前系统现状

| 模块 | 现有实现 | 评价 |
|------|---------|------|
| 模型 | MTLTransformer (3/5/10D) | 单一架构，缺乏对比 |
| 因子 | 11个基础特征 (价量+技术指标) | 缺乏高级因子 |
| 数据 | 日频行情 (OHLCV) | 缺乏另类数据 |
| 决策 | 纯量化排序 | 无逻辑验证 |

### 1.2 升级目标

构建 **LSTM + 高级因子 + LLM 逻辑门（可选）** 的预测系统：

- **模型层**：用 LSTM 替代 Transformer（更成熟的时间序列方案）
- **因子层**：扩展 APM因子、资金流向因子、GP因子（可选）、情绪因子（可选）
- **决策层**：（可选）引入 LLM 进行信号逻辑验证

**核心策略调整**（2026-01-26）：
- ❌ **取消模型融合**：LSTM 直接替代 Transformer（成熟路径）
- ✅ **聚焦因子工程**：Phase 2 优先于 Phase 1（更高 ROI）
- 🎯 **替代标准**：LSTM IC ≥ Transformer × 0.95

### 1.3 预期收益

| 指标 | 当前 | 目标 |
|------|------|------|
| IC | ~0.05 | > 0.07 |
| 命中率 | ~65% | > 72% |
| 超额收益 | ~3% | > 5% |

3. **因子优先**：性能提升优先通过高级因子工程实现
4. **LLM辅助**（可选）：量化为主，LLM逻辑验证为辅

## 3. ~~模型融合策略~~ ❌ 已取消

**状态**：**已取消**（2026-01-26 决策）

### 3.1 为什么取消融合？

| 原因 | 说明 |
|------|------|
| **缺乏先例** | 量化领域少有 LSTM+Transformer 融合的成熟案例 |
| **复杂度高** | 需要统一接口、动态权重、时间对齐等复杂机制 |
| **风险大** | 实现和调优难度大，效果不确定 |
| **维护成本** | 多模型维护增加系统复杂度 |

### 3.2 替代方案：LSTM 直接替代

**策略**：
```python
# 不再需要融合机制
if LSTM.IC >= Transformer.IC * 0.95:
    使用 LSTM  # ✅ 正式切换
else:
    保持 Transformer  # ❌ 替代失败，回退
```

**优势**：
- ✅ **简单明确**：单模型架构，易维护
- ✅ **成熟路径**：大量成功先例可参考
- ✅ **降低风险**：避免复杂融合机制带来的不确定性

### 3.3 LLM 置信度调整（可选）

**如果实施 Phase 4（LLM 增强）**：

```python
if LLM_verdict == "reject":
    final_conf = 0
else:
    final_conf = quant_conf × (1 + llm_weight × (adjustment - 1))
```

**说明**：LLM 层与模型层解耦，不影响 LSTM 替代策略

## 4. 新增因子设计

### 4.1 APM 因子（Asymmetric Price Movement）

**原理**：捕捉隔夜/盘中收益差异，反映知情交易者信息优势

```python
overnight_ret = open[t] / close[t-1] - 1
morning_ret = close[t] / open[t] - 1
APM = morning_ret - overnight_ret
```

**预期夏普比率**：~1.5

### 4.2 GP 因子（遗传规划挖掘）

**原理**：使用遗传规划自动演化非线性因子公式

**输入**：OHLCV + VWAP
**算子**：`+, -, *, /, log, sqrt, rank, delay, ts_mean, ts_std`
**输出**：高IC非线性因子

**预期年化超额**：~6%

### 4.3 资金流向因子

**数据源**：北向资金、龙虎榜席位

```python
northbound_flow = 北向资金净流入 / 成交额
institution_signal = 机构席位买入 - 机构席位卖出
```

### 4.4 情绪因子

**数据源**：财经新闻、公告

```python
sentiment_score = SentimentAnalyzer(news_texts)  # [-1, 1]
sentiment_ma5 = ts_mean(sentiment_score, 5)  # 5日平滑
```

## 5. LLM 增强层设计

### 5.1 信号验证 Agent

**职责**：对量化信号进行逻辑验证

**输入**：
- 量化预测（股票、收益、置信度）
- 市场环境（大盘、北向、行业）
- 近期新闻

**输出**：
- 判决：approve / reject / adjust
- 置信度调整因子：0.5 ~ 1.5
- 分析理由

### 5.2 调用策略

- **批量调用**：每日推荐 Top-20 → LLM 验证 → 筛选 Top-10
- **结果缓存**：相同股票+环境组合缓存7天
- **成本控制**：单次推荐 < 0.1元

## 8. 风险评估

| 风险 | 概率 | 影响 | 缓解措施 |
|------|------|------|---------|
| LSTM 效果不如 Transformer × 0.95 | 中 | 高 | **回退机制**：保留 Transformer，Phase 1 失败 |
| APM/资金流因子效果不佳 | 低 | 中 | 因子 IC 验证，不达标不上线 |
| GP 因子挖掘计算量大 | 中 | 低 | 离线预计算，增量更新（P2 可选） |
| 新闻数据获取受限 | 高 | 低 | 多源备份，本地缓存（P2 可选） |
| LLM API 成本 | 低 | 低 | DeepSeek 便宜（< ¥1/日），批量调用（P3 可选） |
