# 架构升级设计文档

**版本：** v1.0
**创建日期：** 2025-01-26
**目标：** 基于 LSTM + 高级因子 + LLM 增强的智能量化预测系统

---

## 1. 升级背景与目标

### 1.1 当前系统现状

| 模块 | 现有实现 | 评价 |
|------|---------|------|
| 模型 | MTLTransformer (3/5/10D) | 单一架构，缺乏对比 |
| 因子 | 11个基础特征 (价量+技术指标) | 缺乏高级因子 |
| 数据 | 日频行情 (OHLCV) | 缺乏另类数据 |
| 决策 | 纯量化排序 | 无逻辑验证 |

### 1.2 升级目标

构建 **LSTM + Transformer + 高级因子 + LLM 逻辑门** 的融合预测系统：

- **模型层**：引入 LSTM 与 Transformer 对比/融合
- **因子层**：扩展 GP因子、APM因子、资金流向因子、情绪因子
- **决策层**：引入 LLM 进行信号逻辑验证

### 1.3 预期收益

| 指标 | 当前 | 目标 |
|------|------|------|
| IC | ~0.05 | > 0.07 |
| 命中率 | ~65% | > 72% |
| 超额收益 | ~3% | > 5% |

### 2.2 核心设计原则

1. **分层解耦**：数据、特征、模型、决策各层独立演进
2. **协议统一**：所有模型实现统一输出接口
3. **动态权重**：基于近期表现自动调整模型权重
4. **LLM辅助**：量化为主，LLM逻辑验证为辅

## 3. 模型融合策略

### 3.1 融合的核心挑战

| 挑战 | 解决方案 |
|------|---------|
| 时间频率不一致 | TemporalAligner + PIT对齐 |
| 数据类型异构 | UnifiedFeature 协议 |
| 模型输出异构 | ModelOutput 标准格式 |
| 置信度不同 | 动态权重 + IC归一化 |

### 3.2 推荐融合方案

**初期（Phase 1-2）**：
```
加权平均融合 (验证集IC定权) + LLM过滤
```

**成熟期（Phase 3-5）**：
```
动态权重 (近20日IC) + Stacking元学习 + LLM逻辑门
```

### 3.3 融合公式

**动态权重计算**：
```python
score_i = Σ(IC_i,t × decay^(T-t))  # 带时间衰减的累计IC
weight_i = max(score_i, ε) / Σ(max(score_j, ε))
```

**LLM置信度调整**：
```python
if LLM_verdict == "reject":
    final_conf = 0
else:
    final_conf = quant_conf × (1 + llm_weight × (adjustment - 1))
```

## 4. 新增因子设计

### 4.1 APM 因子（Asymmetric Price Movement）

**原理**：捕捉隔夜/盘中收益差异，反映知情交易者信息优势

```python
overnight_ret = open[t] / close[t-1] - 1
morning_ret = close[t] / open[t] - 1
APM = morning_ret - overnight_ret
```

**预期夏普比率**：~1.5

### 4.2 GP 因子（遗传规划挖掘）

**原理**：使用遗传规划自动演化非线性因子公式

**输入**：OHLCV + VWAP
**算子**：`+, -, *, /, log, sqrt, rank, delay, ts_mean, ts_std`
**输出**：高IC非线性因子

**预期年化超额**：~6%

### 4.3 资金流向因子

**数据源**：北向资金、龙虎榜席位

```python
northbound_flow = 北向资金净流入 / 成交额
institution_signal = 机构席位买入 - 机构席位卖出
```

### 4.4 情绪因子

**数据源**：财经新闻、公告

```python
sentiment_score = SentimentAnalyzer(news_texts)  # [-1, 1]
sentiment_ma5 = ts_mean(sentiment_score, 5)  # 5日平滑
```

## 5. LLM 增强层设计

### 5.1 信号验证 Agent

**职责**：对量化信号进行逻辑验证

**输入**：
- 量化预测（股票、收益、置信度）
- 市场环境（大盘、北向、行业）
- 近期新闻

**输出**：
- 判决：approve / reject / adjust
- 置信度调整因子：0.5 ~ 1.5
- 分析理由

### 5.2 调用策略

- **批量调用**：每日推荐 Top-20 → LLM 验证 → 筛选 Top-10
- **结果缓存**：相同股票+环境组合缓存7天
- **成本控制**：单次推荐 < 0.1元

## 8. 风险评估

| 风险 | 概率 | 影响 | 缓解措施 |
|------|------|------|---------|
| LSTM效果不如Transformer | 中 | 中 | 设计融合机制，取长补短 |
| GP因子挖掘计算量大 | 中 | 低 | 离线预计算，增量更新 |
| 新闻数据获取受限 | 高 | 中 | 多源备份，本地缓存 |
| LLM API成本 | 中 | 低 | 批量调用，结果缓存 |
| 特征维度爆炸 | 低 | 中 | IC筛选，正则化 |
