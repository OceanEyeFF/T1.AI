## 🚨 Phase 3 的关键风险

### 1. 数据源风险 🔴

```python
# AkShare 新闻接口示例
import akshare as ak

# 问题：接口随时可能变化或下线
df = ak.stock_news_em(symbol="财经")  # ⚠️ 不稳定
```

**风险点：**
- AkShare 是免费数据源，接口稳定性无保证
- 新闻数据质量参差不齐
- 可能需要多个备份数据源

### 2. FinBERT 模型部署 🔴

**挑战：**
- 模型体积：~440MB
- 推理速度：CPU 上较慢（~100-200ms/条）
- 需要 transformers 库依赖
- 中文金融文本可能效果不佳（FinBERT 主要训练英文）

**替代方案（也不理想）：**
- 简单词典法：准确率低
- DeepSeek API：增加成本依赖

### 3. 时间对齐复杂 🔴

**问题：** 新闻发布时间与交易日对齐规则复杂

```python
def align_news_to_trading_day(news_time, cutoff_hour=15):
    """
    规则：
    - 15:00 前新闻 → 当日
    - 15:00 后新闻 → 次日
    - 非交易日新闻 → 下一交易日

    ⚠️ 容易引入未来信息泄露
    """
```

### 4. 效果不确定 🔴

- 新闻对股价的影响延迟和持续时间不确定
- 噪音新闻多，有效信息少
- IC 增量可能低于预期

```python
# DeepSeek API（兼容 OpenAI 格式）
client = OpenAI(
    api_key="sk-xxx",
    base_url="https://api.deepseek.com/v1"
)

response = client.chat.completions.create(
    model="deepseek-chat",
    messages=[
        {"role": "system", "content": "你是量化分析师"},
        {"role": "user", "content": "验证该预测信号..."}
    ]
)

# ✅ 简单、稳定、可靠
```

### 2. 成本可控 ✅

**DeepSeek 价格：**
- 输入：¥0.001/1K tokens
- 输出：¥0.002/1K tokens

**每日推荐成本估算：**
```
Top-20 推荐 × 500 tokens/推荐 × ¥0.0015/1K = ¥0.15/日
```

**年成本：** ~¥50

### 3. 提示词可迭代 ✅


```
Phase 0 → Phase 2 → Phase 1 → Phase 5 ✅
```
