# 架构升级实施计划

本目录包含智能量化预测系统 v2.0 的分阶段实施文档。

---

## 实施阶段总览

```
Phase 1 ──▶ Phase 2 ──▶ Phase 3 ──▶ Phase 4 ──▶ Phase 5
 LSTM      因子扩展    情绪因子    LLM增强     模型融合
 集成       工程        模块        层          优化
```

| 阶段 | 名称 | 预计周期 | 核心交付 | 状态 |
|------|------|---------|---------|------|
| Phase 1 | [LSTM模型集成](phase1_lstm.md) | 1-2周 | LSTM预测器 + 统一接口 | 🔲 待开始 |
| Phase 2 | [高级因子工程](phase2_factors.md) | 2-3周 | APM因子 + GP因子框架 | 🔲 待开始 |
| Phase 3 | [情绪因子模块](phase3_sentiment.md) | 1-2周 | 新闻数据源 + 情绪分析 | 🔲 待开始 |
| Phase 4 | [LLM增强层](phase4_llm.md) | 1-2周 | 信号验证Agent | 🔲 待开始 |
| Phase 5 | [模型融合优化](phase5_fusion.md) | 2周 | 动态权重 + Stacking | 🔲 待开始 |

**总计**：8-11周

## 快速导航

### Phase 1: LSTM 模型集成

**目标**：在现有框架中添加 LSTM 模型，建立多模型对比基础

**核心任务**：
- 创建 `LSTMPredictor` 模型类
- 统一模型输出接口 `ModelOutput`
- 训练脚本和配置支持
- LSTM vs Transformer 对比评估

📄 [详细文档](phase1_lstm.md)

---

### Phase 2: 高级因子工程

**目标**：扩展因子库，提升信号质量

**核心任务**：
- APM 因子（隔夜/盘中收益差）
- 资金流向因子（北向资金）
- GP 因子框架（遗传规划挖掘）
- 因子有效性评估工具

📄 [详细文档](phase2_factors.md)

---

### Phase 3: 情绪因子模块

**目标**：引入新闻舆情等另类数据

**核心任务**：
- 新闻数据源适配器
- 情绪分析模型封装 (FinBERT)
- 情绪因子计算与时间对齐
- 宏观政策信号提取

📄 [详细文档](phase3_sentiment.md)

---

### Phase 4: LLM 增强层

**目标**：实现 LLM 信号验证能力

**核心任务**：
- LLM API 抽象层
- 信号验证 Agent
- 批量调用与结果缓存
- 成本控制策略

📄 [详细文档](phase4_llm.md)

---

### Phase 5: 模型融合优化

**目标**：实现多模型融合，提升整体性能

**核心任务**：
- 加权平均融合基础版
- 动态权重（基于近期IC）
- Stacking 元学习
- 融合效果评估

📄 [详细文档](phase5_fusion.md)

---

## 验收标准

### 技术验收

| 阶段 | 验收标准 |
|------|---------|
| Phase 1 | LSTM 可独立训练，输出格式与 Transformer 一致 |
| Phase 2 | 新因子 IC > 0.02，因子间相关性 < 0.7 |
| Phase 3 | 情绪因子正常计算，时间对齐无未来信息 |
| Phase 4 | LLM 调用成功率 > 95%，单次成本 < 0.05元 |
| Phase 5 | 融合后 IC > 单模型最优 IC |

### 业务验收

| 指标 | 当前 | Phase 5 目标 |
|------|------|-------------|
| 平均 IC | ~0.05 | > 0.07 |
| 命中率 | ~65% | > 72% |
| 月超额收益 | ~1% | > 1.5% |
