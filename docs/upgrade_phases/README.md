## 快速导航

### 🚨 Phase 0: 基础系统完成（新增）

**目标**：打通端到端流程，验证当前系统效果

**核心任务**：
- 序列数据集构建器（生成训练数据）
- 推荐引擎核心逻辑（生成Top-10榜单）
- MTL 训练脚本（端到端训练）
- 推荐验证器（评估命中率/IC）

**关键性**：🚨 **所有后续 Phase 的前置条件**

📄 [详细文档](phase0_baseline.md)

---

### 🌟 Phase 2: 高级因子工程（提前）

**目标**：扩展因子库，直接提升 IC（**最高性价比**）

**核心任务**：
- ⭐ APM 因子（隔夜/盘中收益差）- 预期 IC +0.02
- ⭐ 资金流向因子（北向资金）- 预期 IC +0.015
- GP 因子框架（遗传规划挖掘）- 可选
- 因子有效性评估工具

**预期收益**：IC 从 0.05 → 0.06-0.08

📄 [详细文档](phase2_factors.md)

---

### Phase 1: LSTM 模型替代

**目标**：**用 LSTM 替代 Transformer，选择更成熟的时间序列预测方案**

**核心任务**：
- 实现 `LSTMPredictor` 模型（保持与 MTLTransformer 相同输出格式）
- LSTM 训练脚本和配置
- **LSTM vs Transformer 对比验证**（关键）
- 替代决策：LSTM IC ≥ Transformer × 0.95 才正式切换

**为什么替代而非融合？**
- ✅ 成熟路径，大量成功先例
- ✅ 架构更简洁，易维护
- ❌ 模型融合缺乏先例，风险高

📄 [详细文档](phase1_lstm.md)

---

### Phase 3: 情绪因子模块

**目标**：引入新闻舆情等另类数据

**核心任务**：
- 新闻数据源适配器
- 情绪分析模型封装 (FinBERT)
- 情绪因子计算与时间对齐
- 宏观政策信号提取

📄 [详细文档](phase3_sentiment.md)

---

### Phase 4: LLM 增强层

**目标**：实现 LLM 信号验证能力

**核心任务**：
- LLM API 抽象层
- 信号验证 Agent
- 批量调用与结果缓存
- 成本控制策略

📄 [详细文档](phase4_llm.md)

---

### ~~Phase 5: 模型融合优化~~ ❌ 已取消

**状态**：**已取消**（2026-01-26 决策）

**取消原因**：
- ❌ 缺乏成熟先例和参考资料
- ❌ 实现复杂度高，风险大
- ✅ **采用 LSTM 替代策略**（更成熟的路径）

**替代方案**：
- Phase 1 改为 LSTM **替代** Transformer（而非共存融合）
- 单模型架构更简洁、易维护
- 如需提升性能，优先通过 Phase 2（因子扩展）实现

## 快速决策指南

### 应该从哪里开始？

1. **Phase 0** - 必须完成，打通基础流程
2. **Phase 2** - 最高性价比，直接提升 IC

### 为什么现在 Phase 1 是 LSTM 替代而非集成？

- ✅ **成熟路径**：LSTM 替代 Transformer 有大量成功先例
- ✅ **架构简洁**：单模型维护更容易
- ❌ **融合风险**：多模型融合缺乏参考，实现复杂
- 🎯 **决策标准**：LSTM IC ≥ Transformer × 0.95 才正式切换

### Phase 5（融合）为什么取消了？

- ❌ **缺乏先例**：量化领域少有 LSTM+Transformer 融合的成熟案例
- ❌ **复杂度高**：需要统一接口、动态权重、Stacking 等复杂机制
- ✅ **替代方案**：LSTM 直接替代 Transformer（更成熟、更简单）
- 💡 **性能提升**：优先通过 Phase 2（高级因子）实现

### Phase 3/4 可以跳过吗？

- ✅ **可以** - 这两个阶段是锦上添花
- **如果要做**：建议 **Phase 4（LLM）优先**
  - 🟢 LLM API 调用简单，DeepSeek 便宜
  - 🔴 情绪因子数据源风险高，实现复杂
- **核心路径**：Phase 0 → Phase 2 → Phase 1 ✅（完成）

### 核心路径总结

```
Phase 0 (基础系统) → Phase 2 (高级因子) → Phase 1 (LSTM 替代)
   3-5天                2-3周                1-2周
                                               ↓
                                         核心路径完成 ✅
                                      （预计 4-6 周）
```
