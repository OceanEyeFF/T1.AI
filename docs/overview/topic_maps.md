1. 先确定主题：`交易` / `数据` / `训练`

## 4. 维护规则

- 主题映射只做导航，不重复定义内容。
- 新增主题时，优先复用现有文档，不要为了凑层级再写重复说明。
- 某个主题如果缺某一层文档，应补该层，而不是把别层文档硬塞进来。
