# 未来状态蓝图

本文档把仓库中多份过细的未来方案抽象为一份长期蓝图，用来替代“阶段太细、状态易过时”的未来拆解文档作为主入口。

## 1. 北极星目标

项目未来应成为一个面向 A 股中短周期选股的研究与执行平台，具备四个稳定能力：

1. 数据可追溯：任一信号都能回放到原始数据、特征版本和可用时间点。
2. 评估可交易：所有模型与策略必须在真实交易约束下评估，而不是只看离线相关性。
3. 决策可治理：模型输出只是输入，最终组合需要风控、状态识别和执行约束共同决定。
4. 系统可扩展：可以逐步引入新因子、另类数据和辅助模型，而不破坏主流程。

## 2. 长期结构

未来系统保持 `pipeline-first`，主链路固定为：

`数据接入 -> 特征构建 -> 标签与样本管理 -> 模型训练/评估 -> 组合决策 -> 执行反馈 -> 监控重训`

其中长期不变的设计原则：

- 主流程优先可解释、可回放、可审计。
- 新模型、新数据源以模块方式接入，不改交易协议。
- 训练、评估、执行三层必须共享同一时序口径。

## 3. 长期能力方向

### 3.1 模型层

- 保持多 horizon 预测能力，但以可交易指标为最终准绳。
- 允许继续用 LSTM、树模型、轻量集成等成熟方案，不追求模型花样本身。
- 校准、状态切换、模型委员会都属于增强层，不应遮蔽基线效果。

### 3.2 数据与因子层

- 主干仍以日频价量、财务、市场状态为核心。
- 另类数据如新闻、公告、北向资金、跨市场因子作为增量模块逐步接入。
- 任一新因子都必须先通过可用时间验证与 OOS 稳定性验证。

### 3.3 决策与执行层

- 模型分数不能直接等价为交易动作。
- 未来输出应包含推荐、仓位建议、证据解释、风险状态和执行约束。
- 成本、容量、成交失败、风控冻结应是主链路内生部分。

### 3.4 监控与运维层

- 需要稳定的数据刷新、训练调度、OOS 产物落盘和门禁检查。
- 线上重训触发应来自性能衰减、漂移检测或规则变化，而不是手工随意触发。
