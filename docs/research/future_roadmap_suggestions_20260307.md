# 最新代码更新后的后续思路建议（2026-03-07）

本文将后续行动按两个方向整理：

1. **提升过程鲁棒性**（先解决“结论是否稳定可信”）
2. **提升项目表现**（再追求“指标和收益是否更高”）

并按三档优先级排序：

- **P0（立即执行）**：本周内落地，直接影响当前实验可信度与上线风险。
- **P1（近期推进）**：1~2 周推进，目标是稳健增益。
- **P2（中期探索）**：在 P0/P1 稳定后投入，防止过早复杂化。

## A. 提升过程鲁棒性（Process Robustness）

### P0（立即执行）

1. **统一评估口径并强制同窗比较**
   - 所有 ABTest 必须对齐同一 OOS 月份集合；
   - 报告必须同时输出：全时段均值、月度分布、最差月、连续负月；
   - 自动生成 `trial - baseline` 差分表，避免“只看单点均值”。

2. **拆解 calibrated 退化来源（三级归因）**
   - 固定输出三段：`raw_pred -> post_calibration -> post_execution_rule`；
   - 每段都给 `avg_ic / avg_rank_ic / 月胜率 / 最差月`；
   - 若 `calibrated` 持续弱于 `raw`，直接阻断进入候选池。

3. **实验门禁自动化（Gate）**
   - 训练后自动判定 `pass/fail`；
   - 不达标实验自动归档到 nonbest，不进入默认候选；
   - 在 `gate_summary` 写清失败原因（如最差月越界、连续负月超限）。

### P1（近期推进）

1. **数据指纹与切分可追溯**
   - 记录原始数据哈希、特征矩阵哈希、切分清单哈希；
   - 将 hash 写入每个实验 metadata，保证“同结论可复现”。

2. **校准策略保守化**
   - 默认不翻向，仅高置信条件才启用翻向/放大；
   - 加“退化保护”：近 N 周 `calibrated < raw` 连续触发时，降级为恒等映射。

3. **版本化实验模板**
   - 固化通用实验模板（窗口、重训频率、指标面板、门禁阈值）；
   - 新实验必须从模板派生，减少“人为口径漂移”。

### P2（中期探索）

1. **分 regime 评估框架**
   - 牛/熊/震荡分桶报告，观察各桶稳定性；
   - 只在分桶结果一致时，才允许升为默认策略。

2. **错误预算机制（Error Budget）**
   - 对数据延迟、缺失补齐、接口回退分别设误差预算；
   - 预算超限时自动触发降级策略与告警。

## B. 提升项目表现（Performance Improvement）

### P0（立即执行）

1. **双基线并行：LSTM + XGBoost**
   - 默认维持 `dim53(no_hist_hl) + weekly rolling retrain`；
   - 同口径维护 LSTM 与 XGBoost 基线，按月追踪谁更稳。

2. **多头损失重加权（先小改）**
   - 在 `3d/5d/10d` 中下调短期噪声头权重（如 `0.2/0.4/0.4`）；
   - 目标不是追求 raw 峰值，而是提升 `5d/10d calibrated` 稳定性。

3. **窗口长度联合对比**
   - 在周频重训下对比 `12/18/24` 个月窗口；
   - 优先选择“连续负月更少”的配置。

### P1（近期推进）

1. **低复杂度集成器上线验证**
   - 先做 LSTM + XGBoost 等权/近月IC加权；
   - 若最差月收敛、门禁通过，再考虑进入线上候选。

2. **商品因子“弱耦合使用”**
   - 暂不直接并入主 alpha 特征；
   - 优先作为风险开关（仓位上限、行业暴露约束）验证增益。

3. **行业条件注入**
   - 仅在资源/化工/有色等高相关行业启用商品相关特征；
   - 避免全市场硬注入造成噪声扩散。

### P2（中期探索）

1. **Regime 条件模型/专家子模型**
   - 在通胀、能源波动、美元趋势等条件命中时切换子模型；
   - 未命中时回退基线，避免“全时段复杂模型拖累”。

2. **校准层结构升级**
   - 探索分桶校准或分层校准网络；
   - 必须满足“calibrated 全指标不弱于 raw”才保留。

## E. 关键缺口：三头输出如何转成实盘买卖（Signal -> Portfolio -> PnL）

你指出的问题在“接线层”上成立：当前仓库已具备基础成交仿真与风险指标，但尚未把三头预测稳定接入“交易决策层 + 资金仓位层”。

### E1. 决策映射（先定义，再回测）

以三头输出 `score_3d/score_5d/score_10d` 构造统一交易分数：

- `alpha_score = w3 * z(score_3d) + w5 * z(score_5d) + w10 * z(score_10d)`
- 建议初始权重：`w3=0.2, w5=0.4, w10=0.4`（与当前“短头降权”方向一致）
- 每日横截面标准化后排序，形成候选池。

买卖规则（可先做最简版）：

1. **开仓**：`alpha_score` 进入前 `Top K%` 且高于阈值 `buy_th`；
2. **平仓**：跌出 `Top M%`、低于 `sell_th`、或持有天数超过 `max_holding_days`；
3. **换仓节奏**：按周/日调仓（先与训练重训周期保持一致）。

### E2. 资金与仓位管理（必须纳入）

最小可用组合约束：

- 初始资金：`capital_0`（例如 1,000,000）；
- 单票上限：`max_weight_per_stock`（如 5%）；
- 行业上限：`max_weight_per_industry`（如 25%）；
- 持仓数量：`n_positions`（如 20~40）；
- 现金下限：`min_cash_ratio`（如 5%）；
- 仓位调整：按目标权重与现有持仓差额生成订单。

### E3. 成交与交易成本仿真（否则收益失真）

- 成交价格：`next_open` / `vwap`（先固定一种口径）；
- 滑点：按 bps（如 5~20 bps）与成交额分层；
- 手续费+印花税：双边/单边按 A 股规则配置；
- 停牌/涨跌停：不可成交则订单挂起或取消；
- 可成交量约束：不超过当日成交额的一定比例（如 5% ADV）。

### E4. 评估指标（从“预测”升级到“可交易”）

除 IC/RankIC 外，必须新增交易层指标：

- 年化收益、波动、Sharpe、Calmar；
- 最大回撤、回撤持续期；
- 换手率、交易成本占比、胜率、盈亏比；
- 基准超额收益、信息比率；
- 不同市场状态下的分桶表现（牛/熊/震荡）。

### E5. 分优先级落地（建议）

**P0（立即）**：

1. 打通“`score_3d/5d/10d -> alpha_score -> target_weights -> orders`”主链路；
2. 在现有 `PortfolioManager` 基础上补齐换仓门槛与最大持有期；
3. 在现有成本模型基础上补手续费/印花税/滑点拆分；
4. 输出第一版可交易回测报告（PnL/回撤/换手）。

**P1（近期）**：

1. 增加成交可行性（停牌、涨跌停、ADV 容量）；
2. 增加行业/风格暴露约束；
3. 对三头权重与阈值做网格搜索，并纳入 gate。

**P2（中期）**：

1. 做策略集成（LSTM 与 XGB 信号融合）；
2. 做动态仓位（波动目标、回撤控制）；
3. 做在线仿真（paper trading）与真实交易接口预演。

### E6. 建议新增产出物

- `output/reports/portfolio_backtest_summary_*.json`：收益/风险/成本总览；
- `output/reports/order_simulation_detail_*.parquet`：逐笔订单与成交明细；
- `output/reports/position_timeseries_*.parquet`：每日仓位与资金曲线；
- `output/reports/decision_gate_trading_*.json`：交易层门禁结论。


## F. 建议产出物（汇总）

- `output/reports/ic_monthly_comparison_*.json/.md`：当前已存在的统一比较与门禁汇总（基础事实源）；
- `output/reports/ic_pipeline_decomposition_*.json`：三级归因；
- `output/reports/gate_summary_*.json`：门禁与失败原因；
- `output/reports/baseline_dualpanel_*.json`：LSTM/XGB 同窗对照；
- `output/reports/baseline_ensemble_abtest_*.json`：低复杂度集成结果；

> 结论：先用 **P0 的过程鲁棒性改造** 锁定“结论可信”，再用 **P0/P1 的性能路径** 做低风险增益，最后再进入 P2 的结构性升级，能同时提高研发效率与结果稳定性。
