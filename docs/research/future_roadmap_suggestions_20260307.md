# 最新代码更新后的后续思路建议（2026-03-07）

本文将后续行动按两个方向整理：

1. **提升过程鲁棒性**（先解决“结论是否稳定可信”）
2. **提升项目表现**（再追求“指标和收益是否更高”）

并按三档优先级排序：

- **P0（立即执行）**：本周内落地，直接影响当前实验可信度与上线风险。
- **P1（近期推进）**：1~2 周推进，目标是稳健增益。
- **P2（中期探索）**：在 P0/P1 稳定后投入，防止过早复杂化。

---

## A. 提升过程鲁棒性（Process Robustness）

### P0（立即执行）

1. **统一评估口径并强制同窗比较**
   - 所有 ABTest 必须对齐同一 OOS 月份集合；
   - 报告必须同时输出：全时段均值、月度分布、最差月、连续负月；
   - 自动生成 `trial - baseline` 差分表，避免“只看单点均值”。

2. **拆解 calibrated 退化来源（三级归因）**
   - 固定输出三段：`raw_pred -> post_calibration -> post_execution_rule`；
   - 每段都给 `avg_ic / avg_rank_ic / 月胜率 / 最差月`；
   - 若 `calibrated` 持续弱于 `raw`，直接阻断进入候选池。

3. **实验门禁自动化（Gate）**
   - 训练后自动判定 `pass/fail`；
   - 不达标实验自动归档到 nonbest，不进入默认候选；
   - 在 `gate_summary` 写清失败原因（如最差月越界、连续负月超限）。

### P1（近期推进）

1. **数据指纹与切分可追溯**
   - 记录原始数据哈希、特征矩阵哈希、切分清单哈希；
   - 将 hash 写入每个实验 metadata，保证“同结论可复现”。

2. **校准策略保守化**
   - 默认不翻向，仅高置信条件才启用翻向/放大；
   - 加“退化保护”：近 N 周 `calibrated < raw` 连续触发时，降级为恒等映射。

3. **版本化实验模板**
   - 固化通用实验模板（窗口、重训频率、指标面板、门禁阈值）；
   - 新实验必须从模板派生，减少“人为口径漂移”。

### P2（中期探索）

1. **分 regime 评估框架**
   - 牛/熊/震荡分桶报告，观察各桶稳定性；
   - 只在分桶结果一致时，才允许升为默认策略。

2. **错误预算机制（Error Budget）**
   - 对数据延迟、缺失补齐、接口回退分别设误差预算；
   - 预算超限时自动触发降级策略与告警。

## B. 提升项目表现（Performance Improvement）

### P0（立即执行）

1. **双基线并行：LSTM + XGBoost**
   - 默认维持 `dim53(no_hist_hl) + weekly rolling retrain`；
   - 同口径维护 LSTM 与 XGBoost 基线，按月追踪谁更稳。

2. **多头损失重加权（先小改）**
   - 在 `3d/5d/10d` 中下调短期噪声头权重（如 `0.2/0.4/0.4`）；
   - 目标不是追求 raw 峰值，而是提升 `5d/10d calibrated` 稳定性。

3. **窗口长度联合对比**
   - 在周频重训下对比 `12/18/24` 个月窗口；
   - 优先选择“连续负月更少”的配置。

### P1（近期推进）

1. **低复杂度集成器上线验证**
   - 先做 LSTM + XGBoost 等权/近月IC加权；
   - 若最差月收敛、门禁通过，再考虑进入线上候选。

2. **商品因子“弱耦合使用”**
   - 暂不直接并入主 alpha 特征；
   - 优先作为风险开关（仓位上限、行业暴露约束）验证增益。

3. **行业条件注入**
   - 仅在资源/化工/有色等高相关行业启用商品相关特征；
   - 避免全市场硬注入造成噪声扩散。

### P2（中期探索）

1. **Regime 条件模型/专家子模型**
   - 在通胀、能源波动、美元趋势等条件命中时切换子模型；
   - 未命中时回退基线，避免“全时段复杂模型拖累”。

2. **校准层结构升级**
   - 探索分桶校准或分层校准网络；
   - 必须满足“calibrated 全指标不弱于 raw”才保留。

## C. 建议排期（两周可执行版）

### Week 1（P0 主体）

- 完成同窗比较与差分报告；
- 完成 calibrated 三段归因与 gate 自动化；
- 跑通 LSTM/XGB 双基线月度面板；
- 启动多头损失重加权与 `12/18/24` 窗口对照。

### Week 2（P1 起步）

- 完成数据指纹写入 metadata；
- 完成 LSTM+XGB 低复杂度集成回测；
- 完成商品因子“风险开关”实验；
- 输出候选清单（只保留 gate=pass 方案）。
