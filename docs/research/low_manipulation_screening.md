# A股"低操盘程度"股票筛选研究

> 独立研究笔记 | 2026-06-22
>
> 研究命题：如何从全市场筛选出被庄家/游资/大资金控盘操纵概率低的股票。
> 方法论：反向思维——先刻画"易被操纵"的完整画像，再逐维取反，构建可量化的排除性筛选体系。

---

## 第一部分：易被操纵股票的正向画像（"庄股五维"）

### 维度一：规模——控盘成本的经济学

**核心逻辑：** 操纵一只股票需要的资金量与流通市值正相关。流通市值越小，控盘成本越低，操纵越可行。

| 指标 | 易操纵特征 | 逻辑 |
|------|-----------|------|
| 流通市值 | < 30亿（弹性+流动性边界） | 数亿资金即可影响股价 |
| 日均成交额 | < 3000万 | 建仓/出货不会产生显著价格冲击 |
| 股价绝对值 | < 10元（低价股） | 同等资金可买更多股数，便于对倒制造活跃假象 |

**实践经验阈值：**

- 流通市值 < 20亿：单一游资（数千万级）即可制造显著波动
- 流通市值 20-50亿：小型团队（数亿级）可阶段性控盘
- 流通市值 50-100亿：需要多个资金协同，操纵难度上升
- 流通市值 > 200亿：操纵成本过高，基本排除"坐庄"可能（但"市值管理"灰色地带仍存在）

### 维度二：筹码——控盘的物质基础

**核心逻辑：** 操纵的前提是筹码集中。如果筹码高度分散在成千上万散户手中，任何单一资金都无法主导价格。

| 指标 | 易操纵特征 | 逻辑 |
|------|-----------|------|
| 股东户数 | < 10000户（极度集中），甚至 < 5000户 | 筹码高度集中在少数账户，容易形成控盘 |
| 股东户数变化率 | 连续2-3季环比下降 > 15% | 筹码正在加速集中（主力吸筹信号） |
| 前十大股东持股占比 | > 65% | 少数股东掌控绝大部分流通筹码 |
| 户均持股市值 | 极高（如 > 500万） | 说明每个账户持有大量市值，是集中而非分散 |
| 实控人/大股东性质 | 合伙企业、投资机构、自然人 | 而非国资/产业资本，其背后可能隐藏一致行动人 |

**极端案例参照：**

- 德隆系"老三股"：合金投资股东仅4000人，德隆控制90%以上流通盘
- 菲林格尔（2019）：股东户数3258户，逼近退市红线（< 2000户）
- 赛恩斯：股东2382户，股价从21元暴涨至148元

### 维度三：价格行为——"人为痕迹"的可观测信号

**核心逻辑：** 正常股票的价格由市场合力形成，走势自然、有逻辑、与大盘共振。庄股的价格由少数人"画"出来，必然留下僵硬、不自然的痕迹。

#### 3.1 K线层面的异常特征

| 特征 | 具体表现 | 可量化方式 |
|------|---------|-----------|
| **独立走势** | K线不与大盘/行业指数共振，走出独立行情 | 个股日收益率与沪深300日收益率的相关系数 < 0.3 |
| **刺猬K线** | 大量长上影/下影线（试盘、洗盘痕迹） | 上/下影线占比 > 实体2倍的K线比例 > 30% |
| **长期横盘后暴拉** | 3个月内振幅 < 15%，随后数日暴拉 > 50% | 横盘期振幅/暴涨期振幅的比值极度异常 |
| **锯齿状走势** | 日内分时僵硬、犬牙交错、缺乏"美感" | 需分钟级数据量化 |
| **尾盘异动** | 尾盘最后30分钟突然拉升或打压（"骗线"） | 尾盘30分钟收益率占全天收益率比例 > 60% |

#### 3.2 成交量/换手率异常

| 特征 | 具体表现 | 可量化方式 |
|------|---------|-----------|
| **极低换手率（已控盘）** | 日均换手率 < 0.5%，甚至连续多日 < 0.1% | 筹码已被锁死，市场无人交易 |
| **异常高换手（对倒）** | 日换手率 > 15%，但股价不涨或微涨 | 主力通过自买自卖制造活跃假象 |
| **换手率突变** | 长期 < 0.5% → 突然单日 > 10% | 控盘后的暴力拉升或出货 |
| **无量上涨、放量下跌** | 上涨日缩量、下跌日放量 | 典型的出货结构 |

**换手率分层参考（A股经验值）：**

- < 0.5%：极不活跃，可能是高度控盘庄股或僵尸股
- 0.5%-1%：低活跃，需警惕
- 1%-3%：正常水平（70%的A股在此区间）
- 3%-7%：相对活跃
- 7%-10%：强势股
- 10%-15%：庄家密切操作区间（需高度警惕）
- > 15%：极高换手，大概率是对倒或短线游资接力

#### 3.3 涨跌停频率

| 特征 | 易操纵信号 |
|------|-----------|
| 频繁涨跌停 | 年涨跌停次数 > 15次 |
| 连续涨停后连续跌停 | A字型走势，典型庄股出货 |
| 涨停打开后反复封板 | 游资接力不稳定 |

### 维度四：龙虎榜行为——资金的"身份证"

**核心逻辑：** 龙虎榜是观察个股资金结构的窗口。"干净"的龙虎榜呈现多机构合力、买卖均衡；"脏"的龙虎榜充满对倒、一家独大、散户接盘等信号。

| 特征 | 易操纵信号 | 量化方式 |
|------|-----------|---------|
| **上榜频率** | 频繁上榜（如近3月上榜 > 5次） | 正常股票很少触发龙虎榜阈值 |
| **对倒行为** | 同一席位同时出现在买卖前五 | 席位重叠检测 |
| **一家独大** | 买一金额占买方总额 > 30%（甚至 > 50%） | 买一占比 |
| **拉萨天团占比高** | 买方或卖方中"东方财富拉萨"席位 ≥ 3个 | 散户集中营，反向指标 |
| **游资风格** | 知名一日游游资（如溧阳路、桑田路等）反复出现 | 席位黑名单匹配 |
| **买卖力量失衡** | 买方总额 > 卖方总额 × 1.5（或反之） | 净买入率 > 50% |
| **量化席位主导** | 华泰证券总部、中金上海等量化席位占比 > 30% | 次日抛压风险高 |

### 维度五：基本面——"故事"的可信度

**核心逻辑：** 庄股需要"题材"配合拉升出货。基本面越差、越依赖"讲故事"的公司，越容易成为操纵标的——因为没有估值锚，股价可以随意定价。

| 特征 | 易操纵信号 |
|------|-----------|
| 业绩 | 连续亏损或微利，ROE < 3%，扣非净利润常年为负 |
| 资本运作 | 频繁实控人变更、重大资产重组、蹭概念、改名 |
| 监管记录 | 被证监会立案调查/行政处罚/通报批评 |
| 审计意见 | 非标准无保留意见（保留意见、无法表示意见等） |
| 大股东质押 | 大股东质押比例 > 70%（爆仓风险+动机不纯） |
| 关联交易 | 关联交易占比高且复杂 |
| 蹭热点 | 频繁在互动平台释放"概念"信息 |

## 第二部分：反向推导——"低操盘程度"的筛选框架

基于上述"易操纵"画像，逐维取反，形成以下排除性筛选体系。**核心原则：不是选出"好股票"，而是排除"可疑股票"。**

### 第一层：规模屏障（硬门槛，一票否决）

| 指标 | 条件 | 理由 |
|------|------|------|
| 总市值 | > 200亿 | 排除中小盘，大幅提高操纵成本 |
| 流通市值 | > 100亿 | 即使考虑前十大锁定，实际流通盘仍足够大 |
| 近20日日均成交额 | > 1亿 | 确保流动性充裕，单一资金进出不会引起剧烈波动 |

**边际讨论：**

- 如果策略必须纳入中小盘（如中证500/中证1000成分股），可将市值门槛放宽至 > 50亿，但必须叠加后续所有维度的严格过滤
- 市值门槛并非绝对免疫（大盘股也存在"市值管理"灰色操作），但概率大幅降低

### 第二层：筹码分散度（核心指标）

| 指标 | 条件 | 理由 |
|------|------|------|
| 最新股东户数 | > 30000户 | 排除筹码高度集中的"庄股候选" |
| 近2季股东户数变化 | 无连续2季环比下降 > 20% | 排除正在被集中吸筹的标的 |
| 前十大股东持股占比 | < 55% | 确保筹码有足够的市场分散度 |
| 户均持股市值 | < 100万 | 排除"人均千万"的集中型筹码结构 |

**注意区分：机构集中 vs 庄家集中**

这是一个重要的 nuance。茅台、宁德等白马股的前十大股东占比也很高（60-70%），但它们不是庄股。关键区分在于：

- **机构集中（安全）：** 前十大中大量是公募基金、社保、保险、北向资金等正规机构
- **庄家集中（危险）：** 前十大中以自然人、投资公司、信托计划、有限合伙为主

因此，应进一步细化：

| 细化指标 | 条件 |
|----------|------|
| 机构持股占流通市值比（公募+社保+保险+QFII+北向） | > 5%（至少有正规机构背书） |
| 前十大中"非正规机构"（自然人+投资公司+有限合伙+信托）占比 | < 30% |
| 单一自然人/投资公司持股 | < 5%（排除隐形的单一控制人） |

### 第三层：价格行为自然度

#### 3.1 走势同频性

| 指标 | 条件 | 计算方式 |
|------|------|---------|
| Beta（vs 沪深300，近120日） | 0.6 ≤ β ≤ 1.4 | 排除独立走势的庄股 |
| 日收益率与沪深300相关系数（近60日） | > 0.4 | 走势应与大盘有基本同步性 |
| 相对行业指数的跟踪误差 | 不过大 | 排除逆行业大势的独立品种 |

#### 3.2 换手率健康区

| 指标 | 条件 |
|------|------|
| 近20日日均换手率 | 0.8% ~ 6%（自由流通股本口径更准确） |
| 近20日换手率标准差 | < 5%（排除换手率剧烈波动——对倒信号） |
| 单日换手率 > 15%的天数（近60日） | ≤ 2天 |
| 单日换手率 < 0.3%的天数（近60日） | ≤ 5天（排除僵尸庄股） |

#### 3.3 涨跌停洁净度

| 指标 | 条件 |
|------|------|
| 近120日涨跌停次数 | ≤ 8次 |
| 近120日连续2日以上涨/跌停次数 | ≤ 1次（排除连续打板操纵） |
| 是否存在"涨停次日跌停"的A字杀 | 近120日无此模式 |

#### 3.4 其他价格行为检查

| 指标 | 条件 |
|------|------|
| 近60日尾盘30分钟异常波动（涨跌幅 > 3%）次数 | ≤ 3次 |
| 近60日日内振幅 > 10%的天数 | ≤ 3次 |
| 股价是否在近120日内出现"横盘3月+暴拉50%+"模式 | 排除 |

### 第四层：龙虎榜洁净度

| 指标 | 条件 |
|------|------|
| 近90日上龙虎榜次数 | ≤ 3次（正常股票很少触发阈值） |
| 若上过榜：是否存在对倒痕迹（同席位买卖同现） | 无 |
| 若上过榜：买一占比 > 30% 的次数 | 0次 |
| 若上过榜：卖方全为机构+买方全为游资 | 排除（机构出逃+游资接盘信号） |
| 若上过榜：拉萨席位 ≥ 3个 | 排除（散户接盘信号） |

### 第五层：基本面可信度

| 指标 | 条件 |
|------|------|
| 近3年扣非净利润 | 至少2年为正 |
| 最新ROE | > 3% |
| 最新审计意见 | 标准无保留意见 |
| 近2年是否发生实控人变更 | 否 |
| 近2年是否被证监会立案调查/行政处罚 | 否 |
| 大股东质押比例 | < 50% |
| 是否ST/*ST | 否 |
| 近1年是否有"蹭热点"式更名 | 否 |

## 第三部分：综合评分框架

将上述五层转化为一个综合打分体系，便于在回测中灵活使用。

### 设计原则

1. **硬排除优先：** 规模、ST、立案调查等为一票否决项
2. **维度独立：** 各维度信号不重复计数
3. **阈值可调：** 根据策略风格（大盘/中小盘）调整门槛

### 建议评分表

#### 第一关：一票否决（任一触发即排除）

| 编号 | 条件 |
|------|------|
| H1 | 流通市值 < 50亿 |
| H2 | 近20日日均成交额 < 5000万 |
| H3 | 为ST/*ST |
| H4 | 近2年证监会立案调查/行政处罚 |
| H5 | 审计意见非标准无保留 |

#### 第二关：减分项（满分100，扣完为止）

| 维度 | 指标 | 减分条件 | 分值 |
|------|------|---------|------|
| 筹码 | 股东户数 < 30000 | 触发 | -15 |
| 筹码 | 股东户数连续2季环比降 > 20% | 触发 | -15 |
| 筹码 | 前十大持股 > 60% | 触发 | -10 |
| 筹码 | 前十大中"非正规机构"占比 > 40% | 触发 | -10 |
| 价格 | Beta < 0.5 或 > 1.5 | 触发 | -10 |
| 价格 | 近60日与沪深300相关系数 < 0.3 | 触发 | -10 |
| 价格 | 换手率日均 < 0.5% | 触发 | -10 |
| 价格 | 近60日涨跌停 > 10次 | 触发 | -10 |
| 龙虎榜 | 近90日上榜 > 5次 | 触发 | -10 |
| 龙虎榜 | 上榜中有对倒/一家独大/拉萨占比高 | 触发 | -10 |
| 基本面 | ROE < 3% 或连续亏损 | 触发 | -10 |
| 基本面 | 大股东质押 > 50% | 触发 | -10 |
| 基本面 | 近2年实控人变更 | 触发 | -5 |

**合格线：≥ 60分（即扣分 ≤ 40）**

### 简化版本（仅用最常见数据）

如果不考虑数据获取难度，完整版是最优的。但在实践中，以下6个指标已经能排除绝大多数操控标的：

1. **流通市值 > 100亿**（规模屏障）
2. **股东户数 > 30000 且 无连续大幅下降**（筹码分散）
3. **近60日日均换手率 1%-5%**（流动性健康）
4. **近60日与沪深300相关系数 > 0.35**（走势同频）
5. **非ST，近2年无处罚记录**（基本面干净）
6. **机构持股（公募+北向）> 3%**（有正规资金参与定价）

## 第四部分：边界情况与讨论

### 4.1 大盘蓝筹 ≠ 零操纵

工商银行、中国石油等超大盘股虽然不会被"坐庄"，但存在以下灰色地带：

- **"市值管理"：** 大股东与机构配合，通过增减持、回购、信息发布节奏影响股价
- **衍生品联动：** 通过期权/期货与现货联动进行套利性操纵
- **指数权重效应：** 被动基金调仓产生的价格冲击被利用

**结论：** 本框架主要针对"游资控盘型"操纵，对"灰色市值管理"的防御力有限。

### 4.2 机构重仓的"拥挤交易"风险

机构重仓本身不是操纵，但极端拥挤（如公募前五大重仓占前十大 > 70%）可能导致：

- 买盘枯竭后的踩踏式下跌
- 季末"粉饰窗口"后的收益反转

这不是"操纵"，但同样带来不健康的量价行为。如果策略追求"自然市场定价"，应额外关注机构拥挤度。

### 4.3 注册制下的新变化

全面注册制后：

- 退市常态化 → ST/壳价值下降 → 传统壳股操纵减少
- 科创/创业板涨跌幅20% → 操纵的资金门槛上升（但波动放大器效应也更强）
- 大数据监管（上交所/深交所监察系统）→ 传统坐庄手法更难藏身，但手法也在进化

### 4.4 数据滞后性问题

股东户数等数据来自季报，滞后1-4个月。当季报显示筹码分散时，实际情况可能已发生变化。缓解方式：

- 结合更高频的代理指标（换手率、大单流向等）交叉验证
- 将股东户数作为"慢变量"背景，而非实时触发器

## 第五部分：与现有回测框架的集成建议

结合本仓库 `ashare_lab` 的回测框架，可以将上述筛选体系作为 `universe.py` 的扩展：

```python
# 伪代码示意
def is_low_manipulation(symbol: str, data_context) -> bool:
    """综合判断是否为低操盘程度标的"""
    # 第一关：硬排除
    if is_st(symbol): return False
    if has_penalty(symbol): return False
    if float_mcap(symbol) < 50e8: return False  # 50亿
    
    # 第二关：评分
    score = 100
    score -= penalty_ownership_concentration(symbol)
    score -= penalty_price_behavior(symbol)
    score -= penalty_dragon_tiger(symbol)
    score -= penalty_fundamentals(symbol)
    
    return score >= 60
```

在策略中，`target_weights` 方法可以这样使用：

- 方案A（硬过滤）：`universe = [s for s in all_symbols if is_low_manipulation(s)]`
- 方案B（软加权）：在权重计算中给予低操纵度标的正溢价
