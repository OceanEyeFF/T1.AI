# 新闻与公告数据源建议

本文档用于补齐新闻/公告来源的统一入口，服务于情绪因子与事件信号研究。

## 1. 使用目标

- 为股票池提供可回溯的事件特征输入。
- 支持“事件发生时间”与“交易可用时间”严格对齐，避免未来信息泄露。

## 2. 数据类型

- 公司公告：财报、分红、停复牌、重大事项。
- 新闻快讯：公司新闻、行业新闻、宏观新闻。
- 研报摘要（可选）：仅作辅助特征，不直接作为交易指令。

## 3. 时间对齐要求

- 必须保留原始发布时间（精确到分钟更佳）。
- 日频策略默认仅允许使用 `t` 收盘前可得信息（遵循 `../interfaces/protocol.md`）。
- 无法确认发布时间的数据，不进入严格回测。

## 4. 工程建议

- 原始文本、结构化事件和模型特征分层存储，避免重复加工。
- 对每条事件保留 `source`、`published_at`、`ingested_at`、`symbol`、`event_type`。
- 先做规则基线（关键词/模板），再做 LLM 或深度模型增强。

## 5. 风险与边界

- 数据版权与接口调用限制需在接入前确认。
- 情绪因子和事件因子默认属于可选增强，不应阻塞核心日频链路。
